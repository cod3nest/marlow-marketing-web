The service

Marlow ingests tickets from sources you connect, triages them, and dispatches AI agents that run in isolated sandboxes. The agents open pull requests or produce artifacts on your behalf, against the repositories and storage destinations you have configured.

Your responsibilities

  • You keep your API tokens, OAuth grants, and account credentials secure.
  • You configure workflows and integrations correctly for the systems you connect.
  • You are responsible for the content of any pull request an agent opens against your repositories. Review before merging.
  • You do not use Marlow to violate the law or harm other systems or people.

Usage

Agent compute and underlying model token usage are metered per run for internal cost accounting. There is no external billing or subscription.
