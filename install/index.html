The Marlow CLI

Install in one line.

Tickets to pull requests, from your terminal. Write tickets, watch runs stream by, and manage sandboxes and env vars — without leaving the shell.

macOS · Linux
$ curl -fsSL https://getmarlowai.com/install.sh | bash

No Node · No Bun · No npm — a single self-contained binary

Using itView source
One command
Detects your OS and CPU, pulls the matching native binary, and drops it on your PATH. macOS and Linux, Apple Silicon and Intel.
Verified
Binaries ship with a published SHA-256. The installer checks it before anything lands on disk and aborts on a mismatch — and warns loudly, rather than failing silently, if no checksum is published for a build.
Zero dependencies
The Bun runtime is baked into the binary. Nothing to install first — no Node, no Bun, no npm or bunx. Just run marlow.
Using it

From login to first run

Every command takes --json, and switches it on automatically when piped, so it drops straight into scripts. A failed run exits non-zero.

01

Log in

Opens your browser, mints a personal CLI token, and saves it to ~/.marlow/config.json. On a headless box, add --manual to paste a token instead.

terminal
$ marlow login
02

Create a ticket

Submit work to a project. Add --agent to dispatch immediately and --watch to follow the run live as it streams steps.

terminal
$ marlow tickets create -p checkout-api \
    --title "Add CSV export to billing" \
    --agent coding-low --watch
03

Watch the runs

List runs, open one for its step tree, or tail logs until it finishes.

terminal
$ marlow runs
$ marlow runs logs <id> --follow
Reference

The commands

Auth

marlow login
Log in via a browser handoff (or --manual to paste a token)
marlow whoami
Show your email, active org, and token preview
marlow orgs use <slug>
Switch the active organization

Work

marlow projects
List projects
marlow tickets create -p <project> --title <t>
Submit a ticket (--agent dispatches, --watch follows)
marlow runs [--status <s>]
List runs with status glyphs
marlow runs logs <id> --follow
Tail a run's logs until it finishes

Project config

marlow containers push --image <ref>
Push into your own registry with your docker login
marlow env set -p <project> KEY=VALUE
Create or update env vars (idempotent)
marlow env ls -p <project>
List env vars (secrets show a preview)

Pin a version or change the install location

The installer honors a few environment variables — pin MARLOW_VERSION, redirect with MARLOW_INSTALL_DIR, or pass --version through the pipe.

pin a version
$ curl -fsSL https://getmarlowai.com/install.sh | bash -s -- --version 0.1.0

Need an account first?

Sign in to mint a CLI token from the console’s CLI access page, then run marlow login.
